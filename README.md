# Actividad-HTML-sem-ntico-validaci-n-W3C
En esta actividad cambié las etiquetas genéricas <div> por etiquetas semánticas para que la estructura de la página fuera más clara. Por ejemplo, cambié div class="header" por header class="header", div class="menu" por nav class="menu", cambié títulos con strong por h1 y h2, la fecha por time y la cita por blockquote entre otros, cuidando mantener las clases para conservar los estilos de CSS
